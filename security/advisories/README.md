# Security Advisories

This page documents all publicly disclosed security vulnerabilities affecting EEZ BB3 firmware, hardware, and integrated components.

## Overview

EEZ BB3 takes cybersecurity seriously. We follow responsible disclosure practices and publish security advisories to inform users of potential vulnerabilities and available fixes. All advisories are coordinated with security researchers and released only after patches are available or 90 days have passed since initial report.

## For Users

- **Check this page regularly** for security updates affecting your EEZ BB3 device
- **Update firmware promptly** when security patches are released
- **Review advisory details** to understand the impact and required actions
- **Report new vulnerabilities** using our [Security Policy](../../SECURITY.md)

## For Researchers

- **Responsible disclosure**: Report vulnerabilities to info@envox.hr rather than creating public issues
- **Coordinated timeline**: We commit to patching within 90 days for most vulnerabilities
- **Public credit**: Researchers are credited in advisories (unless they request anonymity)
- **Safe harbor**: Good-faith security research is protected under our Security Policy

## Advisory Severity

All advisories are rated using the [CVSS v3.1 scoring system](https://www.first.org/cvss/v3.1/specification-document):

- 🔴 **Critical** (9.0–10.0): Immediate action required
- 🟠 **High** (7.0–8.9): Update recommended
- 🟡 **Medium** (4.0–6.9): Consider updating
- 🟢 **Low** (0.1–3.9): Available in next release

## Current Status

EEZ BB3 firmware is actively maintained with security updates released regularly. Users are encouraged to keep their devices updated to the latest firmware version.

For questions or to report a vulnerability, see our [Security Policy](../../SECURITY.md).
